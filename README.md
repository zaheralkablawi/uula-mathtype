# UULA MathType Code

إضافة باوربوينت مستقلة: تقرأ معادلات MathType القديمة في الشرائح وتحفظ داخل كل واحدة (كود مخفي `UULA_AEQ`) نصها بصيغة UULA Arabic Math — نفس الكود الذي تحفظه UULA Arabic Math في صورها.

بعدها: حدد المعادلة القديمة ← «تعديل» في UULA Arabic Math ← يظهر كودها ← «إدراج» فتحل المعادلة الجديدة مكانها وتُحذف القديمة.

- `taskpane.html` يفتح دائمًا أحدث نسخة من `app.html`.
- `python3 build.py` يبني `app.html` من `src/app.html` و`src/core.js` (محرك القراءة).
- ملف التنصيب: `UULA-MathType-Code.xml` — على الماك انسخه إلى
  `~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef/`
